# Gra Idle Drwal

Gra w przeglądarce: rąb drzewa, buduj, handluj, prowadź karczmę – sam albo z kolegami online (do 6 osób).

**Zagraj:** https://jarzynskimaciej-debug.github.io/drwal/

- Na telefonie otwórz link w przeglądarce (Chrome, Safari) – działa też na iPhonie.
- Gra online: **Dołącz** → wpisz kod pokoju od kolegi albo kod serwera.
- Serwer na komputerze: plik „Drwal SERWER” otwiera grę z dopiskiem `?serwer` – świat działa cały czas, telefony tylko dołączają.

Silnik 3D: three.js (MIT), połączenia: PeerJS (MIT), style: Tailwind CSS (MIT).
